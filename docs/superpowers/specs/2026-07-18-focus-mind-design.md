# Focus Mind 产品与技术设计规格

日期：2026-07-18
状态：已确认
首版平台：macOS 桌面应用 + 浏览器开发预览

## 1. 产品目标

Focus Mind 是一个本地优先的 Todo 与正向计时应用，围绕“主题—目标—任务”组织工作，并通过日、周、月日程回顾计划与实际专注结果。

首版交付 macOS 桌面应用。浏览器模式只用于快速预览和调试 UI，不作为正式数据版本。iPad、macOS Widget、账号、服务器同步和多设备同步放入后续阶段，但首版架构不得阻碍这些扩展。

## 2. 首版范围

### 包含

- 主题、目标、任务三级管理。
- 普通任务、每天重复任务、每周完成 N 次任务。
- 日、周、月日程。
- 全局单任务正向计时和多段专注记录。
- 本地 SQLite 持久化、自动备份、导入和导出。
- 可安装 macOS 应用。
- 使用模拟数据的浏览器开发预览。

### 不包含

- 登录、云端服务器和多设备同步。
- iPad 正式适配。
- macOS WidgetKit 小组件。
- 协作、提醒通知和自然语言输入。
- 逾期状态和跳过重复实例。

## 3. 技术方案

- React + TypeScript + Vite 构建界面。
- Tauri 2 提供 macOS 窗口、文件、退出恢复和打包能力。
- SQLite 作为正式本地数据源。
- UI、业务规则与数据访问分层，React 组件不得直接执行 SQL。
- 浏览器预览使用内存 repository 和固定模拟数据；刷新后无需保留。
- 将来服务器版可新增 HTTP repository，服务端使用 PostgreSQL 等并发数据库，无需重写 UI 和核心业务规则。

建议模块：

- `domain`：状态、重复实例、时间与统计规则。
- `application`：新增、编辑、完成、计时和删除等用例。
- `repository`：存储接口。
- `infrastructure/sqlite`：本地持久化实现。
- `infrastructure/preview`：浏览器模拟实现。
- `ui`：React 页面和组件。
- `desktop`：Tauri 平台能力。

## 4. 核心实体

### 4.1 主题 Theme

- ID。
- 名称。
- 颜色。
- 同层排序位置。
- 创建和更新时间。

主题颜色决定关联任务在日程和专注片段中的颜色。修改主题颜色后，历史记录的显示颜色也随之改变；专注记录不保存冗余颜色。

### 4.2 目标 Goal

- ID。
- 所属主题 ID。
- 名称。
- 同层排序位置。
- 创建和更新时间。

### 4.3 任务 Task

- ID。
- 所属目标 ID。
- 名称。
- 可选描述。
- 开始日期。
- 结束日期。
- 重复类型：`none`、`daily`、`weekly_quota`。
- 每周配额；仅 `weekly_quota` 使用，必须为正整数。
- 任务本体完成状态与完成时间。
- 同层排序位置。
- 创建和更新时间。

所有原设计中的“截止日期”统一改为“结束日期”。开始日期和结束日期只有日期，没有计划时刻。开始日期必须早于或等于结束日期。

### 4.4 重复实例 TaskOccurrence

- ID。
- 所属任务 ID。
- 周期标识或计划发生日期。
- 可选绑定日期。
- 状态：未完成或已完成。
- 完成时间。
- 创建和更新时间。

每天重复实例具有固定计划发生日期。每周配额实例先属于某一自然周但没有具体日期，开始专注或完成时绑定到当天。

### 4.5 专注记录 FocusSession

- ID。
- 所属任务 ID。
- 可选重复实例 ID。
- 实际开始时间。
- 实际结束时间；活动计时期间为空。
- 创建来源：计时器或完成时手动补填。
- 创建和更新时间。

时长永远由结束时间减开始时间派生，不单独存储。全库最多存在一个结束时间为空的活动记录。

## 5. 任务与重复规则

### 5.1 普通任务

- 从开始日期起进入每日待办，完成前持续显示。
- 超过结束日期仍继续显示，不标记逾期。
- 在主题页或日程页完成，都会完成任务本体。
- 恢复为未完成时保留原日期和专注记录。

### 5.2 每天重复

- 在开始日期与结束日期构成的闭区间内，每天生成一个独立实例。
- 某日未完成的实例保留在原日期，不跳过、不标记逾期。
- 后续日期仍正常生成新实例。
- 日程中完成只完成当前实例。
- 主题页完成任务本体会停止生成完成日之后的实例。

### 5.3 每周完成 N 次

- 每个自然周生成 N 个无具体日期实例。
- 未绑定实例出现在该周每天“今日待办”底部，以聚合项显示“本周还剩 N 次”。
- 用户从聚合项选择“今天进行”、开始计时或直接完成时，选择一个未绑定实例并绑定到当天。
- 已绑定实例按普通当日实例显示。
- 本周完成进度显示为 `已完成数 / N`。
- 未完成配额不结转下周、不标记逾期，并保留在历史周数据中。
- 达到 N 次后，本周不再显示可开始实例；下一自然周重新生成。

### 5.4 编辑重复规则

- 历史实例和历史专注记录永远不重算。
- 名称和描述更新到所有界面的当前展示。
- 重复类型、日期范围和每周配额只影响今天及未来。
- 修改当前周配额时，已完成实例不可被删除；若新配额小于已完成数，当前周显示为已超额完成，未来周使用新配额。
- 从重复改为不重复时保留历史实例，今天之后不再生成新实例。

## 6. 状态规则

任务状态自动派生，不提供手动状态下拉框：

- `专注中`：任务拥有全局唯一活动计时。
- `已完成`：普通任务本体已完成，或重复任务本体已终止。
- `进行中`：未完成且至少有一条已保存专注记录。
- `未完成`：未完成且没有专注记录。

重复实例自身只有未完成和已完成。重复任务本体在主题页完成后停止产生未来实例；既有实例和历史记录保留。

完成普通任务或重复实例时：

- 已有关联专注记录：直接完成。
- 没有关联专注记录：必须填写精确到分钟的实际开始和结束时间，自动创建正式专注记录后完成。
- 结束必须晚于开始，不能晚于当前时间，且不得与其他专注记录重叠。

## 7. 主题页

主题、目标和任务三栏在 macOS 首版始终同时可见，各自独立滚动：

- 左栏显示主题。
- 中栏显示当前主题的目标。
- 右栏显示当前目标的任务。

三栏均支持同层拖动排序。主题和目标在栏标题处新增；任务在任务栏标题处新增。

### 7.1 新增与编辑

- 新建主题：名称、预设色板或自定义颜色。
- 新建目标：名称、所属主题；默认当前主题。
- 新建任务：名称、描述、所属目标、开始日期、结束日期、重复类型和对应参数；默认当前目标。
- 修改所属目标等同于移动任务，历史记录随任务移动。
- 名称必填并去除首尾空格；同一父级下允许重名。
- 表单有未保存内容时，关闭需确认。

### 7.2 卡片操作

- 任务卡正面提供完成勾选和开始计时。
- 编辑、删除放在右键菜单；右键菜单是首版 macOS 的正式入口。
- 主题与目标同样通过右键菜单编辑或删除。
- 已完成任务移到右栏底部独立区域，降低透明度，允许恢复未完成。
- 空主题、空目标和空任务列表提供明确新增入口。

### 7.3 提前开始任务

- 从主题任务列表启动尚未到开始日期的普通任务时，开始日期自动改为当天。
- 若当天晚于原结束日期，结束日期也自动改为当天。
- 今天不是每天重复实例发生日或不在重复日期范围内时，禁止启动。
- 每周配额任务若本周仍有剩余实例，启动时绑定一个实例到今天；无剩余实例则禁止启动。

## 8. 日程页面

顶部提供日、周、月视图和日期导航。

### 8.1 日视图

- 默认今天，可浏览其他日期。
- 分为“待办”和“已完成”。
- 普通任务从开始日期起在完成前持续显示。
- 每天重复任务显示该日实例。
- 每周配额已绑定实例显示在对应日期；未绑定配额聚合项显示在该周每天待办底部。
- 卡片可以开始计时、完成，右键编辑或删除。
- 浏览历史或未来日期时只能查看和编辑数据，不能从非系统当天启动活动计时。

### 8.2 周视图

- 七天并列，采用类似 Apple 日历的纵向时间轴。
- 每天顶部设置计划任务区域，显示该日计划但未完成的任务；未绑定周配额显示在周级“本周待安排”区域。
- 时间轴只显示实际专注片段，不展示任务计划时刻。
- 片段显示任务名、起止时间和主题色。
- 跨午夜记录视觉上按午夜拆到两天，底层保持一条记录。
- 同一时段不允许存在重叠专注记录。
- 点击片段可查看任务、目标和主题，并编辑或删除记录。

### 8.3 月视图

- 每个日期格显示该日计划任务、已绑定重复实例和实际专注片段。
- 有专注记录的项目按片段开始时间排序，显示任务名称与片段起止时间。
- 同一任务有多个片段时逐段显示。
- 有片段但任务仍未完成时，除片段外再保留一条无时间的未完成任务项。
- 没有专注片段的任务统一排在日期格底部。
- 已完成和未完成通过勾选、透明度和状态图标区分。
- 日期格空间不足时在格内上下滚动，不使用展开弹层。
- 点击任务打开任务详情；点击片段打开记录详情。

## 9. 计时页面

- 任务选择器只显示系统当天安排且未完成的任务和实例。
- 普通任务可选范围为开始日期不晚于当天且尚未完成。
- 每天重复只显示当天实例。
- 每周配额仍有剩余时可选择并自动绑定一个实例到今天。
- 页面使用一个状态按钮：未计时时为“开始”，计时时为“结束本段”。设计稿中的多个按钮只作为视觉参考。
- 全局同时只能有一个活动计时。
- 启动另一任务时，先结束并保存当前段，再启动新段；两个写入在单个事务中完成。
- 再次启动同一任务会创建新专注记录。
- 活动显示值为系统当前时间减开始时间，不按秒持久化。
- 今日概览显示专注次数和总时长。
- 今日记录显示已结束片段和正在进行片段。
- 修改或删除记录后，今日概览、周视图和月视图立即重算。

### 9.1 跨午夜

- 数据库存一条记录。
- 每日时长按自然日边界拆分。
- 专注次数只计入开始日。
- 周/月时间轴按日期边界绘制为多个视觉片段。

### 9.2 记录编辑

- 可修改开始和结束时间或删除。
- 结束必须晚于开始，不能晚于当前时间。
- 不允许与任何其他专注记录重叠。
- 时长即时派生，不提供直接修改时长字段。

### 9.3 异常退出恢复

应用启动发现活动计时状态时，必须阻止继续计时并要求选择：

- 按当前时间结束并保存。
- 手动选择结束时间并保存。
- 丢弃本段。

手动时间仍须通过全部合法性检查。系统时间变化造成负时长时，同样进入恢复流程。

## 10. 删除规则

- 删除任务永久删除其全部实例和专注记录。
- 删除目标永久删除其全部任务、实例和专注记录。
- 删除主题永久删除其全部目标、任务、实例和专注记录。
- 所有删除都必须二次确认。
- 确认框明确列出将删除的目标、任务、实例和专注记录数量。
- 级联删除在单个数据库事务中完成；失败则全部回滚。
- 删除成功后所有统计和日程立即重算。

## 11. 桌面行为与浏览器预览

### macOS

- 记住上次窗口大小和位置。
- 设置三栏可用的最小窗口尺寸；更窄时整体横向滚动，不压坏布局。
- 活动计时状态写入 SQLite，不依赖窗口持续打开。
- 应用退出不自动结束活动计时；下次启动进入恢复流程。
- 第二阶段为右键操作增加 iPad 长按或更多按钮入口。

### 浏览器预览

- `vite` 开发服务可直接在浏览器查看，无需打包。
- 使用模拟 repository 和演示数据。
- 明确显示“预览模式”。
- 不保证刷新后保留数据。
- 禁用文件备份、导入、异常退出恢复等 Tauri 专属能力。
- 业务组件通过 repository 接口运行，禁止在组件内判断或调用 SQLite。

## 12. 数据安全与迁移

- SQLite 启用外键约束并使用事务。
- 数据库模式只通过版本化迁移脚本更新。
- 每日首次启动创建滚动备份，保留最近 7 份。
- 支持导出完整备份和从备份导入。
- 导入前自动备份当前数据库。
- 导入损坏或不兼容文件时保持原数据库不变。
- 所有时间保存为绝对时间戳，日期计算统一使用用户当前系统时区。
- 日历查询按可见日期范围读取，不一次加载全部历史。

SQLite 数据主要占用磁盘；个人 Todo 规模下预计远小于 WebView 本身的内存开销。通过索引、范围查询和分页保证记录增长后仍可用。

## 13. 错误处理

- 所有写操作先通过领域校验，再进入数据库事务。
- 数据库写入失败时不得显示虚假成功，并提供可重试提示。
- 自动备份失败不阻止启动，但显示非阻塞提醒。
- 切换计时任务时，结束旧段失败则不得启动新段。
- 导入失败自动回滚。
- 重复实例生成使用唯一约束保证多次启动不会重复生成。

## 14. 视觉实现要求

- 以用户提供的三张设计稿和静态 HTML 为视觉依据。
- 静态 HTML 只用于参考，不直接作为生产代码。
- 将页面拆分为可复用 React 组件。
- 将颜色、字号、间距、圆角和阴影整理为设计 token。
- Google 字体和 Material Symbols 不作为正式版的在线运行依赖；改用本地资源或合适的系统字体/图标。
- 主题颜色必须保证文字对比度和专注片段可读性。
- 各独立滚动区域只在需要时显示滚动条。

## 15. 测试范围

### 领域测试

- 普通任务日期与自动提前开始。
- 每天实例生成、漏做保留和终止。
- 每周 N 次实例生成、每日聚合提醒、日期绑定、完成进度和周末结算。
- 重复规则编辑时历史保持不变。
- 完成时专注记录补填。
- 状态派生。
- 跨午夜统计。
- 时间重叠校验。

### 集成测试

- 全局单活动计时和任务切换事务。
- 异常退出恢复三种分支。
- 级联删除及统计刷新。
- 数据库迁移、自动备份、导出、导入和失败回滚。
- 重复实例生成幂等性。

### UI 测试

- 主题三栏选择、排序和右键操作。
- 日视图完成规则。
- 周视图时间轴和跨午夜片段。
- 月视图排序、未完成项和格内滚动。
- 计时页任务候选范围。
- 浏览器预览不调用桌面专属 API。

## 16. 首版验收标准

- 三个主页面与设计稿的核心视觉、层级和交互一致。
- 主题、目标、任务和三类重复规则可完整使用。
- 关闭并重新打开应用后数据完整。
- 活动计时异常退出后不会静默丢失。
- 所有统计只来源于专注记录。
- 修改或删除记录后所有页面立即一致。
- 大量历史记录下，日程只查询可见范围。
- 可生成可安装的 macOS 应用。
- 可通过浏览器快速预览 UI。
- 服务器、iPad 和 Widget 尚未实现，但替换存储和增加平台 UI 时无需重写领域规则。

## 17. 后续阶段

1. iPad 横竖屏布局、触控排序和长按菜单。
2. macOS WidgetKit，通过 App Group 共享只读摘要或数据库。
3. 服务器 API、账号、PostgreSQL 和多设备同步。
4. 同步冲突策略、离线队列和端到端数据迁移。
